主要取舍：
1. **删去**：概念定义页、研究问题页、方法瓶颈页、议题/部门异质性页、三个机制的章节分隔页、局限页。概念定义融进讲稿一句话带过；局限改成“研究议程”。面试委员更关心你接下来做什么。
2. **合并**：数据 + 参照系 + 访谈 + 形似 + 神似五页合成一页，用大数字表达规模。
3. **标题改成结论句**：例如“反直觉：政治立场不再决定话语”，委员只看标题也能抓住发现。
4. **开场不报题目**：先给两段施政报告让委员自己看出变化，再提问题。
5. **优秀博士论文**：封面和致谢页各放一次徽章，开场白提一句，不反复强调。

## 需要你确认

1. **荣誉名称**：按清华官方用语写成“清华大学优秀博士学位论文”。如果证书上的名称不同（比如带年份），请告诉我。

4. **应聘院系**：第 11 页研究议程写了“两岸关系中的话语整合”。如果应聘的是台湾研究院，可以把这一条放大；如果是公共管理或政治学，可改成课程与团队建设方向。
5. **用时**：逐字稿正文约 1,850 字（不计数字和标点），按正常语速约 8.5–9.5 分钟，留出了余量。请计时试讲一遍。
