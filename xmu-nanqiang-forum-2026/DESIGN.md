## 一句话风格

画廊白底上的巨字海报：80–96px、700 字的标题压在轻盈的正文之上，色彩只出现在产品本身。
页面底色是 #f5f5f7（比纯白低一度），卡片靠色值分层、不用阴影；唯一的行动色是 #0071e3，
只出现在「Buy」胶囊按钮和导航链接上。

## 2. 字体

SF Pro 为 Apple 自有字体，不可直接商用；替代：Inter / system-ui。

| 字体 | 替代 | 字重 | 字号 | 行高 | 用途 |
| --- | --- | --- | --- | --- | --- |
| SF Pro Display | Inter, system-ui | 600, 700 | 21, 24, 28, 32, 40, 56, 80, 96px | 1.04–1.20 | 全部营销标题、产品名、章节标题。700 字重 + 80–96px 是本页标志性手法 |
| SF Pro Text | Inter, system-ui | 300, 400, 500, 600 | 12, 14, 17, 18, 20, 24, 44px | 1.24–1.50 | 正文、导航、说明、按钮、脚注。默认正文 400 / 17px |

### 字阶（字号 / 行高 / 字距，字距单位 px）

| 角色 | 字号 | 行高 | 字距 |
| --- | --- | --- | --- |
| caption | 12 | 1.33 | -0.26 |
| body-sm | 14 | 1.43 | -0.04 |
| body | 17 | 1.47 | -0.10 |
| subheading | 20 | 1.40 | -0.20 |
| heading-sm | 24 | 1.29 | -0.36 |
| heading | 40 | 1.17 | -0.60 |
| heading-lg | 56 | 1.07 | -0.90 |
| display | 96 | 1.04 | -2.11 |

规则：字距随字号收紧——96px 为 -2.11px，56px 为 -0.9px，17px 正文为 -0.1px。

## 4. 组件

### Primary Buy Button（唯一转化 CTA）

- 背景 `#0071e3`，文字 `#ffffff`，圆角 999px，内边距 8px 16px，SF Pro Text 17px / 400。
- 出现在全局导航和产品子导航。全页唯一的 #0071e3 元素。

### Dark Pill Button（深色背景上的 Buy）

- 背景 `#000000`，文字 `#ffffff`，圆角 999px，内边距 16px（横向）。
- 背景是产品渐变时改用黑色，保证在鲜艳渐变上可读。

### Ghost Text Button（次级「Learn more」）

- 背景透明，文字 `#1d1d1f`，圆角 0，无内边距。就是加粗的纯文本链接。

### Rounded Ghost Button（功能切换标签）

- 背景透明，文字 `#1d1d1f`，圆角 28px。Calls and Texts / Handoff / iPhone Mirroring / AirDrop 等标签切换。

### Frosted Pill Selector（地区选择器 / 分段控件）

- 背景 `rgba(210, 210, 215, 0.64)`，文字 `rgba(0,0,0,0.56)`，圆角 36px，`backdrop-filter: blur(20px)`。
- 磨砂玻璃 = 临时浮层或页内选择器，与所有不透明按钮区分开。

### White Feature Card（主内容卡）

- 背景 `#ffffff`，圆角 28px，**无阴影**，内边距 28px。靠比 #f5f5f7 底亮一级来「浮起」。

### Fog Feature Card（白色背景上的备用卡）

- 背景 `#f5f5f7`，圆角 28px，无阴影，内边距 28px。父级是白色时反转面/卡关系，读作「凹陷」而非「浮起」。

### Dark Feature Card（高对比产品细节卡）

- 背景 `#000000`，圆角 28px，无阴影，文字 `#ffffff`。浅色卡片网格里的单张强调卡。

### Global Navigation Bar（全局导航）

- 背景 `#f5f5f7`（展开时 `rgba(250,250,252)`），高约 44px，链接 SF Pro Text 12px / 400 / `#1d1d1f`，
  Apple logo SVG 填充 `#000000`。吸顶，滚动时变为半透明。
- 最右侧是 Buy 主按钮。

### Sticky Product Sub-Nav（产品子导航）

- 背景 `#ffffff`，下边框 `1px solid #e8e8ed`，高约 52px，链接 SF Pro Text 14px / 400 / `#1d1d1f`，
  激活链接带 3px `#1d1d1f` 下划线，右侧 Buy 胶囊 `#0071e3`。hero 滚过后吸顶。

### Product Color Swatch Chip（配色选择）

- 直径 28px 的圆或短胶囊，背景取配色 token，圆角 999px。
- 选中态加 3px 实线描边：浅色底用 `#1d1d1f`，深色底用 `#ffffff`。

### New Badge

- 背景透明，文字 `#1d1d1f`，圆角 0，SF Pro Text 12px / 600。就是纯文本标签，
  不是胶囊——反常规的徽章，读作编辑注记而非 UI 芯片。

### Carousel Pagination Dot

- 激活：`#1d1d1f`，约 8×8px，圆角 999px；未激活：`rgba(210,210,215,0.64)`。
- 水平居中于轮播下方，间距 6px。

## 5. Do's / Don'ts

### Do

- 全部功能卡用 28px 圆角（#ffffff 和 #f5f5f7 底都一样）。
- #0071e3 只给主「Buy」CTA 按钮，别的 UI 元素一律不用。
- 字距随字号收紧：96px 用 -2.11px，56px 用 -0.9px，17px 正文用 -0.1px。
- #f5f5f7 做页面底、#ffffff 做卡面，绝不反过来——卡永远比父背景亮。
- 56px 及以上的主产品标题用 SF Pro Display 700；600 只给 24–40px 的辅助标题。
- 临时浮层控件（地区选择器、分段选择）用 `rgba(210,210,215,0.64)` + `blur(20px)` 磨砂玻璃。
- 产品配色渐变只做该配色展示区的整幅背景，不做 UI 装饰、卡片底或按钮填充。

### Don't

- 不给任何卡片或容器加 box-shadow。整个高度系统只靠色值，阴影会破坏平光画廊感。
- 不用 #0066cc 做按钮底色——它只是行内文字链接色，用在填充按钮上会与 #0071e3 的 CTA 层级冲突。
- 40px 以下标题不用 300 字重——在这个阈值下 300 字重在白/雾底上会失去清晰度。
- 同一视觉区不并排两个圆角胶囊按钮。999px 半径每区只配一个 CTA。
- 不把产品配色（#dddc8c / #e8d0d0 / #596680）当语义色或 UI 强调色——它们只是产品身份色板和渐变源色。
- SF Pro Display 在 28px 以上不用正字距。
- 超过 2 行的正文段落不居中。Apple 正文在两栏功能布局里左对齐；居中只留给单行 hero 副标题和价格标注。

## 6. 布局

- 最大宽约 1200px 居中，底色 #f5f5f7。
- Hero：整视口居中标题堆叠（产品名 24px → hero 标题 80–96px → 价格副文 17px → 单个 Buy 胶囊），
  产品图在文字折叠线以下出现——经典 Apple 居中堆叠 hero。
- 子导航在 hero 滚过后吸顶，高约 52px。
- 章节节奏：#ffffff 整幅带与 #f5f5f7 带交替，不用明确分隔线——色值变化本身就是分节。
- 功能区：两栏分栏（文字左约 40%、产品图右约 60%）或整幅产品渐变卡。
- 亮点轮播：单栏居中卡片，横向滚动 + 分页点。
- 规格区：左侧标签 / 右侧数值的紧凑两栏表格，body-sm 字号。
- 功能细节卡：2×2 网格，28px 圆角，每张自成一体。
- 导航：顶部半透明吸顶全局导航（12px 文字，约 44px 高）+ 下方吸顶产品子导航（14px 文字，约 52px 高）——
  长页面滚动时两层导航始终可见，章节上下文不丢失。

## 7. 影像

- 产品摄影主导：MacBook 永远是唯一主体，拍在纯白或 Fog（#f5f5f7）面上——
  没有生活场景、没有手（hero 的手托除外）、没有桌面环境。
- Hero 图：笔记本单手从下方托起，近俯视角度，鲜明的 Citrus 配色是整个无彩构图中唯一的色彩注记。
- 配色展示：整幅戏剧渐变（深色→柑橘 / 深色→靛蓝 / 深色→腮红）做背景，打开的笔记本从渐变中浮现——产品即光源。
- 无插画。图标为 SF Symbols 风格：单色、填充/描边混合、表观描边 1.5–2px，
  浅色底用 #1d1d1f，深色卡用 #ffffff。
- 页面重图轻文：每个主要章节都由一张占视口高度 50–80% 的产品图锚定，文字以紧凑组合浮于其上或其下。

## 8. 动效

- 主时长 0.344s（页面切换、卡片出现）；快速反馈 0.1s（悬停、按钮按压）；滚动驱动动画 0.32s ease。
- 默认缓动：CSS 关键字 `ease`（97% 的过渡都用它）。
- 最常见的动画属性是 background-color 和 color（悬停时在中性值之间切换）；
  opacity 驱动章节入场，transform 处理产品图视差和轮播移动。
- 动效性格是「富有表现力」，但以慢缓动锚定，感觉像有重力而非弹跳。

## 整理说明（与原文的差异）

1. **去重**：原文颜色表里「Citrus Gradient `#dddc8c`」和「Citrus Finish `#dddc8c`」是同一个色值，
   整理后只在「产品配色」保留一次，渐变色改用完整的 184° 四段渐变值（见第 1 节和第 8 节）。
   同理 Blush / Indigo 的渐变峰值色与色板色不同，属正常（渐变是深色→亮色的四段过渡），已分开列出。
2. **字距单位统一说明**：原文 Typography 表用 em（-0.022em），Type Scale 表用 px（-2.11），
   两者是同一套值的两种写法（96px × -0.022em ≈ -2.11px），整理版保留 px 表，em 值见原文。
3. **阴影**：本文件通篇「无阴影」，高度只靠色值。Reel 里提到的「文件说不用阴影、又列阴影值」
   的矛盾，在这份文件里不存在——它没有任何阴影 token；若你在别处看到 shadow 值，
   那是 1px 外框线（`1px solid` 描边），不是模糊阴影。
4. **适用范围**：这份是 MacBook Neo 产品页的提取，不是 apple.com 首页也不是 macOS 界面规范；
   拿去做别的产品页时，产品渐变与配色色板要换成自己的产品色，基础规则（色阶、字阶、28px 卡、999px 胶囊）可直接复用。
5. **字体授权**：SF Pro 是 Apple 自有字体，商用项目请用 Inter 或 system-ui 替代；
   字号/字重/字距数值本身不受字体授权限制。
